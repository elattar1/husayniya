# Husayniya

أنشئ تطبيق خدمات متكامل باسم "خدمات الحسينية" يخدم مركز الحسينية بمحافظة الشرقية في مصر.

التطبيق باللغة العربية بالكامل، بتصميم احترافي حديث، واتجاه RTL، ومتوافق مع شاشات الموبايل.

أريد 3 أنظمة مترابطة: واجهة للعملاء، ولوحة لمقدمي الخدمات والمحلات، ولوحة إدارة.

الأقسام: المطاعم والكافيهات، السوبر ماركت، الصيدليات، حجز الأطباء، السباكة والنجارة والكهرباء والصيانة، الملابس والهدايا والخدمات المنزلية.

الخصائص: تسجيل الدخول، البحث حسب الخدمة والمنطقة، صفحات المحلات، سلة المشتريات، حجز المواعيد، طلب الخدمات المنزلية مع الصور، تحديد العنوان، متابعة الطلب، الإشعارات والتقييمات، إدارة العمولات والطلبات والأرباح.

استخدم قاعدة بيانات حقيقية بصلاحيات آمنة، وبيانات تجريبية واضحة. نفذ الوظائف الأساسية فعليًا وليس مجرد صور أو أزرار شكلية. لا تنفذ مدفوعات حقيقية في النسخة الأولى. جهز بنية تسمح بإضافتها لاحقًا. اعرض ما تم تنفيذه وما يحتاج إلى إعداد إضافي.
